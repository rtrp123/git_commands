Understand Dockerfile
Line 1
FROM tomcat:9.0

Means:

Use Tomcat 9 as the base image.

Line 2
COPY target/*.war /usr/local/tomcat/webapps/ROOT.war

Means:

Copy the Maven-generated WAR into Tomcat's webapps folder.

Because it's named:

ROOT.war

your application runs at:

/

instead of:

/projectname/

Your document explains this behavior.

Line 3
EXPOSE 8080

Means:

Document that the container application uses port 8080.

It does not actually publish the port to your computer.

Line 4
CMD ["catalina.sh","run"]

Starts Tomcat in the foreground.

🧠 HARD VIVA — MUST KNOW
Maven
What is Maven?

Maven is a build and dependency management tool for Java projects.

What is POM?

POM stands for Project Object Model and pom.xml contains Maven project configuration and dependencies.

What is dependency?

A library required by the project.

What is .m2?

Maven's local repository.

What is target?

Directory containing generated build artifacts such as WAR/JAR.

What does mvn clean do?

Removes previous build output, mainly the target directory.

What does mvn package do?

Compiles, tests as configured, and packages the application into a JAR/WAR.

🧠 Git VIVA
Git vs GitHub?

Git is a version control system. GitHub is a cloud platform for hosting Git repositories.

What is a branch?

An independent line of development.

Why use a feature branch?

To develop a feature separately without directly modifying the main branch.

What is commit?

A saved snapshot of changes in the Git repository.

git add?

Moves changes to the staging area.

git commit?

Saves staged changes as a commit.

git push?

Uploads local commits to a remote repository.

git pull?

Fetches and integrates changes from a remote repository.

git clone?

Creates a local copy of a remote repository.

git merge?

Combines changes from one branch into another.

git stash?

Temporarily stores uncommitted changes.

git revert?

Creates a new commit that reverses an earlier commit.

🧠 DOCKER VIVA
What is Docker?

Docker is a platform used to package and run applications in containers.

Image vs Container?

Image:

Read-only template used to create containers.

Container:

Running/created instance of an image.

Remember:

IMAGE → creates → CONTAINER
What is Dockerfile?

A text file containing instructions for building a Docker image.

What is FROM?
FROM tomcat:9.0

Specifies the base image.

What is COPY?
COPY target/*.war ...

Copies files from the build context into the image.

What is EXPOSE?

Documents the port the containerized application listens on. It doesn't itself publish the port.

What is docker build?

Builds an image from a Dockerfile.

What is docker run?

Creates and starts a container from an image.

What is -d?

Detached/background mode.

What is -p?

Publishes/maps a host port to a container port.

For:

-p 7089:8080

remember:

7089 = host
8080 = container
What is Docker Hub?

A registry for storing and sharing Docker images.
